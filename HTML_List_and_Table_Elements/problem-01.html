GLA University Admission Handbook

Admission Overview

GLA University provides various undergraduate and postgraduate programs with a focus on quality education, practical learning and career development.

Eligibility

Eligibility: Students must meet the required academic qualifications for the selected program.

Application Deadline: Check the official admission website for the latest deadline.

Application Process

  1. Visit the official admission website.
  2. Check the eligibility requirements.
  3. Fill out the application form.
  4. Upload the required documents.
  5. Pay the application fee.
  6. Submit the application form.

Required Documents

  • 10th Marksheet
  • 12th Marksheet
  • Transfer Certificate
  • Migration Certificate
  • Passport Size Photographs
  • Identity Proof
